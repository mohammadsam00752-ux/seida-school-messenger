# سیدا — پیام‌رسان مدرسه سیدالشهدا کبودرآهنگ

این پروژه یک **نسخهٔ آغازین قابل توسعه** است: وب‌اپ React، قابل نصب به‌صورت PWA، با ورود/ثبت‌نام Supabase و چت متنی زنده از طریق Supabase Realtime.

## امکانات فعلی
- رابط راست‌چین فارسی
- ثبت‌نام با نام، پایه و رشته
- ورود با ایمیل و رمز عبور
- پروفایل جدید به‌صورت پیش‌فرض `pending` است
- نمایش گروه‌ها پس از تأیید حساب
- ارسال و دریافت زنده پیام‌های متنی
- طرح اولیه گروه‌های پایه دهم تا دوازدهم
- manifest و service worker برای نصب PWA

## پیش‌نیاز
- Node.js نسخهٔ 20 یا جدیدتر
- حساب Supabase
- اینترنت برای نصب وابستگی‌ها و استفاده از سرویس ابری

## راه‌اندازی گام‌به‌گام

### ۱) ساخت پروژه Supabase
1. به https://supabase.com برو و وارد حساب شو.
2. یک پروژه جدید بساز و رمز پایگاه داده را در جای امن نگه دار.
3. در پروژه، بخش **SQL Editor** را باز کن.
4. محتوای `supabase/schema.sql` را کامل اجرا کن.
5. در بخش **Project Settings → API**، Project URL و کلید عمومی/Publishable یا anon را بردار.

### ۲) تنظیم پروژه در کامپیوتر
1. پوشه پروژه را از ZIP استخراج کن.
2. فایل `.env.example` را کپی و نام نسخه کپی را `.env` بگذار.
3. مقادیر زیر را در `.env` وارد کن:
   - `VITE_SUPABASE_URL`: آدرس پروژه
   - `VITE_SUPABASE_ANON_KEY`: کلید عمومی (anon/publishable)
4. در ترمینال داخل پوشه پروژه اجرا کن:

```bash
npm install
npm run dev
```

5. آدرسی را که Vite نشان می‌دهد باز کن (معمولاً `http://localhost:5173`).

### ۳) تأیید اولین حساب
برای آزمایش:
1. از داخل سیدا یک حساب ثبت‌نام کن.
2. در Supabase به **Table Editor → profiles** برو.
3. ردیف همان کاربر را پیدا کن و `status` را از `pending` به `approved` تغییر بده.
4. برای ورود آزمایشی، ممکن است لازم باشد تأیید ایمیل را در Authentication تنظیم کنی یا ایمیل را از مسیر تأیید معمول Supabase تأیید کنی.

### ۴) عضویت در گروه
در نسخه اولیه، حساب تأییدشده گروه‌ها را می‌بیند، اما برای ارسال پیام باید عضو گروه باشد. از **Table Editor → rooms** شناسه گروه را بردار و در **room_members** یک ردیف بساز:
- `room_id`: شناسه گروه
- `user_id`: شناسه کاربر از `profiles`

این کار را برای هر کاربر و هر گروه مجاز تکرار کن. این کار دستی است و در مرحله بعد پنل مدیر برای آن می‌سازیم.

### ۵) نصب روی گوشی اندروید
PWA برای نصب از یک آدرس HTTPS میزبانی‌شده مناسب است. پس از انتشار روی سرویس میزبانی:
1. سایت را در Chrome گوشی باز کن.
2. منوی سه‌نقطه را بزن.
3. **Install app** یا **Add to Home screen** را انتخاب کن.

برای نصب معتبر PWA و استفاده واقعی از خارج شبکه محلی، باید پروژه را روی HTTPS میزبانی کنی؛ `localhost` فقط برای توسعه است.

## انتشار روی اینترنت
می‌توانی پروژه را روی سرویس‌های میزبانی سازگار با Vite مانند Vercel یا Netlify منتشر کنی. متغیرهای محیطی `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را در تنظیمات همان سرویس وارد کن و build command را `npm run build` و output directory را `dist` قرار بده.

## نکات امنیتی مهم
- **هرگز کلید `service_role` را در فایل `.env` فرانت‌اند، کد React یا مخزن عمومی قرار نده.** فقط کلید عمومی anon/publishable در مرورگر مجاز است.
- این نسخه برای نمونه‌سازی است، نه استقرار مدرسه بدون بازبینی. پیش از استفاده واقعی، مدیر فنی باید سیاست‌های RLS، تأیید حساب‌ها، عضویت گروه‌ها، ثبت‌نام دانش‌آموزان، گزارش تخلف، پشتیبان‌گیری و حریم خصوصی را بررسی کند.
- فعلاً هیچ پنل مدیریتی امنی داخل برنامه نیست؛ تأیید حساب‌ها و عضویت‌ها از داشبورد Supabase انجام می‌شود.
- پیام‌ها فعلاً متن ساده‌اند؛ ارسال عکس، فایل، پیام صوتی، تماس، اعلان push و رمزگذاری سرتاسری در این نسخه پیاده‌سازی نشده‌اند.
- برای مدرسه، بهتر است حساب‌ها با دعوت‌نامه یا تأیید مدیر فعال شوند و دسترسی کاربران مسدودشده فوراً قطع شود.

## مسیر پیشنهادی مرحله بعد
1. پنل مدیریت امن برای تأیید/مسدودکردن اعضا و مدیریت گروه‌ها
2. دعوت‌نامه یا کد مدرسه برای جلوگیری از ثبت‌نام افراد غریبه
3. انتخاب خودکار گروه بر اساس پایه و رشته
4. ارسال فایل/عکس با Supabase Storage
5. اعلان‌ها و سپس انتشار نسخه اندرویدی بسته‌بندی‌شده
